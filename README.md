# Multitool for Antigravity

[Multitool](https://multitools.pro) is an operational Meta Ads manager for media buyers who run
many ad accounts and Facebook profiles. This plugin connects your Multitool workspace to
Antigravity, so the agent can read and manage your ads from chat.

## What you can ask

- "Show today's spend and results across all my ad accounts"
- "Which campaigns spent more than $50 today with no results?"
- "Why is this ad set not delivering?"
- "Rank my creatives by cost per result over the last 7 days"
- "Pause every ad in campaign X" — the agent shows a preview and waits for your confirmation

## Install

- **Antigravity Marketplace:** Customizations → Marketplace → search for "Multitool" → Add.
- **From GitHub:** `agy plugin install https://github.com/multitool-ads/mcp`

## Sign in

When the plugin connects, Antigravity opens Multitool in your browser. Sign in, choose a
workspace and allow access.

If the browser does not open in Antigravity IDE: press Ctrl+Shift+P, run "Manage MCP Servers",
click Authenticate next to the Multitool server, sign in, then paste the code shown in the browser
and click Submit.

## Changes are safe by design

Every change to your ads is previewed first: you see what will change and which objects are not
eligible. Nothing is sent to Meta until you confirm it in Antigravity.

## Requirements

A Multitool account with your Facebook profiles connected — [multitools.pro](https://multitools.pro).

## Other MCP clients

The same server works in any client that supports remote MCP with OAuth:
`https://mcp.multitools.pro/mcp`

## По-русски

Плагин подключает ваш воркспейс Multitool к Antigravity: агент видит расход, результаты и
креативы по всем рекламным кабинетам и может ставить на паузу, запускать, менять бюджеты и
креативы — каждое изменение сначала показывается на предпросмотре и уходит в Мету только после
вашего подтверждения.

Установка: Customizations → Marketplace → «Multitool» → Add, или командой
`agy plugin install https://github.com/multitool-ads/mcp`. После установки Antigravity откроет
вход в Multitool в браузере — войдите, выберите воркспейс и разрешите доступ.
