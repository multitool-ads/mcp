---
name: multitool-ads
description: Answer questions about the user's Meta ad accounts, campaigns, ad sets, ads and creatives, and make changes to them, through the Multitool MCP server.
---

Use the Multitool tools for anything about the user's Meta advertising: spend, results, cost per
result, statuses, why an ad is not delivering, creatives, auto-rules and Page comments.

- A workspace can be passed by its name. Ask which workspace only when the user has several and
  the question does not say.
- Money is reported in each ad account's own currency. Do not add up amounts in different
  currencies.
- Every read says how fresh the data is. If a period is not synced yet, say so instead of
  reporting zeros.
- To change ads (pause, resume, budget, name, creative), always preview the change first, show the
  user what will change and what is ineligible, and execute only after the user confirms.
